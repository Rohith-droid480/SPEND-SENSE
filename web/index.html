Statistical Algorithm

Category-Specific Modified Z-Score with Raw MAD

Modified Z = 0.6745 × (Candidate Amount − Category Median) / Raw MAD

Standard deviation is distorted by extreme outliers. SpendSense uses the median and Median Absolute Deviation (MAD), which have a 50% breakdown point. A transaction is flagged if and only if |Modified Z| > 3.5. Results are reported strictly as potential outliers, never labeled as fraud.
